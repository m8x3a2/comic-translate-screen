# Test data licenses

Every file under `test_data/` must be redistributable. Record its source and
license here when adding it.

## pages/peppercarrot/

Pages from **Pepper&Carrot** by **David Revoy** — https://www.peppercarrot.com —
licensed under [Creative Commons Attribution 4.0 International (CC BY 4.0)](https://creativecommons.org/licenses/by/4.0/).
Translations are made by the Pepper&Carrot community; translator credits are
listed on each episode page of the website. Files are the "low-res" versions
published on the website, renamed to `<language>_<episode><page>.jpg`; they are
not modified.

## reference/

Outputs of the original comic-translate code (Apache-2.0) run on the pages
above; generated by `tools/reference/gen_reference.py`.

## golden/

`*.jpg` are outputs of this project's pipeline run on the Pepper&Carrot pages
above (text removed and replaced with mock translations, downscaled). They are
adaptations of David Revoy's work under the same **CC BY 4.0** license; the
lettering uses the Pangolin font (SIL Open Font License 1.1, see
`apps/comic_translate/assets/fonts/Pangolin-OFL.txt`). `*.json` and
`golden.json` are generated data.
