# Comic Translate Screen

[English version](README.md)

Перевод комиксов, манги, манхвы и вебтунов на своём компьютере: программа находит
текст, распознаёт, переводит, очищает пузыри и вписывает перевод.

> **Независимый проект.** Comic Translate Screen — переписанная на Dart/Flutter версия
> на основе [ogkalu2/comic-translate](https://github.com/ogkalu2/comic-translate) (Apache-2.0).
> Это **не** официальная версия Comic Translate, проект не связан с её авторами.

## Состояние

Идёт этап 1: перенос оригинального приложения на Flutter для Windows 11, затем Android.
Планы — в [описании архитектуры](docs/ARCHITECTURE.md).

## Принципы

- **По умолчанию всё локально.** Детекция, OCR и очистка выполняются на вашем компьютере.
  Всё, что отправляет данные в сеть, явно помечено в интерфейсе и спрашивает разрешения.
- **Без аккаунтов, кредитов и телеметрии.**
- **API-ключи** хранятся в защищённом хранилище ОС и никогда не попадают в логи и отчёты.
- **Плагины.** OCR, перевод, детекция и очистка — модули с общим интерфейсом; новый
  провайдер = один файл + одна строка регистрации.

## Сборка (Windows)

Нужны Flutter 3.47+, Visual Studio 2022 Build Tools (C++) и включённый режим разработчика Windows.

```bash
flutter pub get
cd apps/comic_translate
flutter build windows
```

Получатся `comic_translate.exe` (приложение) и `cts.exe` (командная строка, см. [docs/CLI.md](docs/CLI.md)).

## Если что-то сломалось

Запустите `cts report` (или кнопку «Собрать отчёт об ошибке» в приложении) и пришлите
получившийся zip. Ключи и путь к вашей папке пользователя в нём замаскированы, картинки
страниц добавляются только по флагу `--with-images`. Подробнее — [docs/DIAGNOSTICS.md](docs/DIAGNOSTICS.md).
