# Comic Translate Screen

[English version](README.md)

Перевод комиксов, манги, манхвы и вебтунов на своём компьютере: программа находит
текст, распознаёт, переводит, очищает пузыри и вписывает перевод.

Автор: [m8x3a2](https://github.com/m8x3a2).

> **Независимый проект.** Comic Translate Screen — переписанная на Dart/Flutter версия
> на основе [ogkalu2/comic-translate](https://github.com/ogkalu2/comic-translate) (Apache-2.0).
> Это **не** официальная версия Comic Translate, проект не связан с её авторами.

## Принципы

- **По умолчанию всё локально.** Детекция, OCR и очистка выполняются на вашем компьютере.
  Всё, что отправляет данные в сеть, явно помечено в интерфейсе и спрашивает разрешения.
- **Без аккаунтов, кредитов и телеметрии.**
- **API-ключи** хранятся в защищённом хранилище ОС и никогда не попадают в логи и отчёты.
- **Плагины.** OCR, перевод, детекция и очистка — модули с общим интерфейсом; новый
  провайдер = один файл + одна строка регистрации.

## Отличия от оригинала (этап 1)

- OCR локальный, как вариант «по умолчанию» в оригинале: PaddleOCR (PP-OCRv5/v6, ONNX) и
  manga-ocr для японского. Новое: системный OCR Windows (на Android позже ML Kit) как лёгкая
  альтернатива без скачивания моделей.
- Перевод: офлайн-заглушка для тестов и один OpenAI-совместимый провайдер
  (OpenRouter, OpenAI, DeepSeek, LM Studio, Ollama, сервер llama.cpp) с промптом оригинала.
  Остальные вернутся по одному. Сервер на `localhost` считается локальным, всё остальное
  помечается и требует разрешения.
- Новое: маленькие страницы (скриншоты, сканы низкого разрешения) увеличиваются перед
  наложением перевода, поэтому буквы остаются чёткими при просмотре и печати (настройка
  «Увеличение»: по умолчанию автоматически, можно ×2/×3/×4 или до заданной ширины;
  варианты с нейросетью — на этапе 2).
- Модели можно хранить в любой папке и ставить из файлов, скопированных с другого
  компьютера (интернет не нужен).
- Проекты: автосохранение включено по умолчанию (в оригинале выключено); история отмены в
  проекте не хранится. Из PDF встроенная картинка берётся, только если страница — это одна
  картинка без видимого текста поверх (оригинал берёт первую картинку любой страницы и мог
  потерять текст); остальные страницы рисуются в 200 dpi (в оригинале — 72).
- Новое: у OpenRouter можно по кнопке узнать остаток ключа, а программа сама ведёт счётчик
  расхода по моделям (запросы, токены, стоимость — сегодня и всего). Счётчик хранится только
  на этом компьютере и никуда не отправляется.
- PSD пишется и читается своим кодом (в оригинале — библиотека PhotoshopAPI) с теми же именами
  слоёв, поэтому файлы подходят обеим программам. Новое: в файле есть готовая склеенная картинка
  (её видят просмотрщики и Krita), у каждого текстового слоя — текст, как его нарисовала программа,
  а данные страницы хранятся внутри файла, так что PSD открывается обратно с распознанным текстом.
  Вертикальный текст сохраняется картинкой, а не текстовым слоем.
- Убраны вход, аккаунты, кредиты, платные облачные OCR и автоматическая проверка обновлений.

## Новое после этапа 1 (этап 2, идёт)

- **Обмен с чатом вручную**: обрезки пузырей (или текст) вы сами отправляете в ChatGPT, Gemini или
  Claude в своём браузере и вставляете ответ обратно; программа сама ничего не отправляет.
- **Офлайн-перевод** английский ↔ русский (OPUS-MT, без интернета и ключей).
- **Комиксы / Сайты и игры**: скриншоты сайтов, игр и визуальных новелл читаются по строкам
  (детектор строк PP-OCRv5), а не по пузырям.
- **Подготовка мелкого текста к распознаванию**: перед распознаванием увеличиваются только кусочки с
  мелким текстом — обычным способом ×1,5 / ×2 или нейросетью трёх уровней (waifu2x CUNet, waifu2x
  Swin-UNet, Fatality Comix от Twittman, лицензия CC BY-NC-SA 4.0 — по умолчанию для комиксов).
  Слипшиеся слова на крошечном тексте можно разделить по словарю; для совсем мелкого текста программа
  подсказывает, что сделать.
- Каждый шаг показывает, сколько занял, а отчёт «Перевести всё» — время каждого шага.
- Неожиданная ошибка сама собирает отчёт (он остаётся на этом компьютере).

## Сборка (Windows)

Нужны Flutter 3.47+, Visual Studio 2022 Build Tools (C++ и компонент «C++ ATL») и включённый режим разработчика Windows.

```bash
flutter pub get
cd apps/comic_translate
flutter build windows
```

Получатся `comic_translate.exe` (приложение) и `cts.exe` (командная строка, см. [docs/CLI.md](docs/CLI.md)).

## Как пользоваться

1. Запустите `comic_translate.exe`. Нажмите «Открыть файлы…» или «Открыть папку…», либо
   перетащите в окно картинки, папку, архив комикса (CBZ, ZIP, EPUB, CBR, CB7), PDF или PSD.
2. Вверху выберите язык оригинала и язык перевода.
3. Нажмите «Перевести всё» (или Ctrl+Enter). Если переводчик отправляет текст в интернет,
   программа сначала спросит разрешения; если не хватает моделей, предложит их скачать и
   покажет размер.
4. Слева — страницы (галочка — переведена), в середине — страница («Оригинал» / «Перевод»,
   колёсико мыши — масштаб), справа — распознанный текст и перевод.
5. «Экспорт» сохраняет переведённые страницы (и, по желанию, очищенные страницы и тексты)
   в папку, ZIP, CBZ, CB7 или PDF — целиком или по главам, а также файлами Photoshop (PSD) со слоями.

### Проекты

- **Ctrl+S** сохраняет работу в файл проекта `.ctsproj`: страницы, рамки, распознанный текст,
  перевод, оформление, маски и шрифты пузырей — всё в одном файле, его можно перенести на другой
  компьютер. Открыть проект: меню «Открыть файлы» → «Открыть проект…», стартовый экран
  («Недавние проекты»), перетаскивание файла в окно или двойной щелчок.
- Проект, у которого есть файл, **сохраняется сам** через пару секунд после каждой правки
  и после каждой страницы «Перевести всё» (можно выключить: «Настройки» → «Общие» → «Проекты»).
  В строке состояния видно: «Сохранено в 21:14» или «Не сохранено».
- Работа, ещё не сохранённая в проект, раз в 2 минуты копируется. Если программа закроется
  из-за сбоя, при следующем запуске она предложит **восстановить прошлую работу**.
- При закрытии окна с несохранёнными изменениями программа спросит: «Сохранить», «Не сохранять»
  или «Отмена».

### Photoshop (PSD)

- В «Экспорте» выберите формат **«PSD (слои для Photoshop)»**. Каждая страница станет файлом
  Photoshop со слоями: «Raw Image» — страница как была, группа «Inpaint Patches» — очищенные
  места, группа «Editable Text» — перевод **редактируемыми текстовыми слоями** (шрифт, размер,
  цвет, обводка, выравнивание, поворот). Слои названы так же, как у оригинального Comic
  Translate, поэтому файлы подходят обеим программам.
- Если перевод нарисован встроенными шрифтами (Pangolin и другие), рядом с файлами появится
  папка `fonts` со шрифтами и их лицензиями: установите шрифт, и Photoshop покажет текст как в программе.
  Без шрифта Photoshop подставит другой, и строки могут перенестись иначе.
- PSD сохраняются в папку или ZIP и по одной странице (для читалок и ленты вебтуна —
  обычные картинки). Очень длинные страницы (выше 30 000 px) сохраняются в формате PSB.
- **Открыть PSD** можно как картинку: «Открыть файлы…» или перетаскиванием. Свой файл
  откроется с распознанным текстом, переводом и очисткой; если вы поправили текст в Photoshop,
  программа возьмёт новый вариант. Файл оригинального Comic Translate откроется так же, но без
  распознанного текста. Файл из другой программы: видимые слои с картинкой склеиваются в
  страницу, текстовые слои становятся переводом, который можно править; программа скажет,
  если какие-то возможности Photoshop (смарт-объекты, маски, режимы наложения) не перенеслись.

### Ручная правка

Над страницей — инструменты и шаги. Шаги работают с текущей страницей и сами делают
недостающее: «Перевести» на новой странице сначала найдёт и распознает текст.

| Что | Как |
|---|---|
| Найти текст → Распознать → Перевести → Маска → Очистить | кнопки над страницей |
| Рука (H): двигать страницу, щелчок выбирает пузырь | колёсико — масштаб, средняя кнопка мыши или левая с зажатым пробелом / Ctrl — двигать в любом инструменте |
| Рамки (R): обвести текст, подвинуть, растянуть за квадратики | Delete — удалить выбранную рамку |
| Перевод (T): перетащить текст, растянуть за углы, повернуть за кружок сверху | двойной щелчок — правка перевода справа |
| Кисть (B) и ластик (E): поправить красную маску перед «Очистить» | `[` и `]` — размер кисти |
| Отменить / повторить | Ctrl+Z / Ctrl+Y |
| Поиск и замена | Ctrl+F |

Шаги можно выполнить сразу для нескольких страниц: выберите их в списке слева щелчком
с **Ctrl** (по одной) или **Shift** (подряд). У каждой страницы свои языки; кнопка рядом
с языками («для всех страниц») появляется, когда у страниц они разные. У инструмента «Рамки»
есть меню «Все рамки»: все больше или меньше на 3 px, удалить все.

Справа у выбранного пузыря можно исправить распознанный текст и перевод, распознать или
перевести только его заново, а в «Оформлении текста» — сменить шрифт (или выбрать файл
шрифта), размер, цвет, обводку, выравнивание, начертание, межстрочный интервал, вертикальный
текст и поворот; «Ко всем на странице» переносит оформление на остальные пузыри.

Переводчик, ключ API (хранится в защищённом хранилище Windows), шрифт, увеличение и модели
настраиваются в «Настройках» (значок шестерёнки). Свои шрифты добавляются в «Настройки» →
«Текст» → «Добавить шрифт…».

### Ключ API и расход

- Ключ вставляется в «Настройки» → «Переводчик». Значок глаза показывает то, что вы ввели,
  до сохранения. У сохранённого ключа видны последние 4 символа («Сохранён: …a1b2»),
  чтобы различать ключи; кнопка «Показать ключ» показывает его целиком (через 30 секунд он
  снова скрывается), «Копировать» — копирует. В журналы и отчёты об ошибках ключ
  не попадает никогда.
- **Заменить** ключ: вставьте новый и нажмите «Заменить». **Удалить**: «Удалить ключ»
  (программа переспросит). Сам ключ на сайте сервиса после этого продолжит действовать —
  если он больше не нужен, отзовите его там.
- У каждого переводчика свой ключ; облачное распознавание (позже) будет хранить свой.
- Для OpenRouter есть кнопка **«Проверить остаток»**: лимит ключа, сколько потрачено и
  осталось, сколько бесплатных запросов осталось сегодня. Ключ отправляется на
  openrouter.ai только по нажатию.
- Ниже — **«Расход на этом компьютере»**: запросы, токены и стоимость по каждой модели,
  сегодня и всего. Программа считает это сама по ответам серверов.

Все горячие клавиши показывает кнопка с клавиатурой над страницей (рядом с «Отменить») или клавиша **F1**.
**F11** — во весь экран и обратно.

## Если что-то сломалось

Пошаговая инструкция для тех, кто тестирует программу: [docs/TESTING.ru.md](docs/TESTING.ru.md).
Коротко: «Настройки» → «Общие» → «Собрать отчёт об ошибке» (или `cts report`), затем
пришлите получившийся zip вместе с описанием, что вы делали. Ключи и путь к вашей папке пользователя в нём замаскированы, картинки
страниц добавляются только по флагу `--with-images`. Подробнее — [docs/DIAGNOSTICS.md](docs/DIAGNOSTICS.md).
