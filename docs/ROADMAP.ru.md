# План развития

## Что уже работает

| Возможность | Где найти и как работает |
|---|---|
| Профили «Свой сервер» | В настройках переводчика. Профили можно создавать, переименовывать, искать и сортировать. Имя ограничено 100 символами. |
| Загрузка моделей | Кнопка «Загрузить модели» запрашивает каталог по адресу выбранного профиля и использует его активный ключ. Идентификатор модели также можно ввести вручную. |
| Подключение по адресу API | Программа добавляет к базовому адресу путь операции, например `chat/completions` или `models`. Сегмент `/v1` нужен, когда он входит в базовый адрес конкретного сервиса. Работающий адрес можно сохранить. |
| Модель по умолчанию на сервере | У «Своего сервера» поле «Модель» можно оставить пустым. В стандартном запросе поле `model` тогда пропускается. Сервер может выбрать модель сам или вернуть ошибку с требованием указать её. |
| Инструкция подключения | Внизу настроек «Своего сервера» есть краткая инструкция и копируемый промпт для нейросети. В промпте описаны три HTTP-операции, поля профиля, переменные шаблона, правила разбора и порядок проверки. |
| Именованные шаблоны | Один шаблон можно создать, отредактировать и назначить нескольким профилям. При удалении шаблона профили возвращаются к своим параметрам. |
| Полные HTTP-запросы | В шаблоне открываются отдельные редакторы для чата и перевода, каталога моделей и сведений о ключе. Для каждой операции можно задать HTTP-метод, относительный путь, заголовки, тело JSON и правила разбора ответа. Полный запрос включается отдельно для каждой операции. |
| Предпросмотр и тест HTTP | Предпросмотр собирает запрос без отправки. Тест отправляется после подтверждения и показывает HTTP-статус, тело ответа и извлечённые значения. Отчёт можно скопировать. Активный ключ подставляется в заголовок из профиля и маскируется в отчёте. |
| Несколько ключей | У каждого профиля свой список ключей, ручной выбор активного и заметки до 100 символов. Значения ключей хранятся в защищённом хранилище ОС. |
| Сведения о ключе | OpenRouter умеет запрашивать сведения по своему встроенному запросу. Для другого сервиса можно настроить запрос и подписать нужные поля ответа в шаблоне. Результат обновляется кнопкой «Обновить сведения о ключе». |
| Тестовый чат и логи | У «Своего сервера» и OpenRouter есть тестовый чат с текстом и изображениями. «Логи» показывают запрос, HTTP-статус и ответ для последней попытки. |
| Отзыв разрешения | Кнопка «Отозвать» в списке разрешённых серверов удаляет сохранённое согласие приложения на отправку данных. При следующей отправке приложение снова спросит разрешение. Ключ остаётся в хранилище. |
| Перенос HTTP-шаблонов и проверка ответа | Именованный шаблон можно импортировать и экспортировать в JSON. Ключи из хранилища не входят в файл. В редакторе можно проверить разбор вставленного JSON с указанным HTTP-статусом без запроса. |
| HTTP-шаблоны OpenRouter | Общий шаблон настраивает чат, каталог и сведения о ключе. Его полные запросы применяются также к сетевому OCR OpenRouter. Пункт «Настройки профиля» возвращает настройки подключения. |

## Распознавание и перевод

- В настройках есть отдельные разделы **«Распознавание»** и **«Очистка»**. В
  «Распознавании» собраны выбор OCR, подключения, модели, режим одного запроса и
  подготовка текста. У очистки свои настройки качества и обработки больших страниц.
- **«Распознать и перевести»** повторно читает текст в рамках выбранным OCR, затем
  переводит распознанный текст выбранным переводчиком. Это могут быть разные модели
  и разные подключения.
- Для сетевого OCR через «Свой сервер» можно выбрать сохранённое подключение и
  отдельно указать модель, которая умеет работать с картинками. Каталог загружается
  через это подключение. Список профилей, адреса, ключи и HTTP-шаблоны общие с
  переводчиком. Активный профиль и модель для OCR выбираются отдельно.
- Если включить **«Распознавать и переводить одним запросом»** у сетевой модели OCR,
  она возвращает распознанный текст и перевод в одном ответе. «Дополнительный
  контекст для переводчика» позволяет указать стиль, имена и терминологию.
- Возле команд видны выбранные OCR и переводчик. «Редактор промпта» добавляет
  свои инструкции для сетевых моделей и проверяет вставленный ответ на двух
  тестовых рамках по правилам рабочего разбора.
- В редакторе можно создавать, редактировать, удалять и выбирать именованные
  заготовки. У OCR и перевода отдельные списки. Выбор копирует инструкции в
  текущий редактор. Сохранение применяет текст к текущим настройкам модели и
  записывает изменения списка.

## Проверка перевода главы

- «Проверка перевода» показывает пропуски текущей главы. Нажатие на строку
  открывает нужную страницу и рамку. Кнопка «Следующий» ведёт к следующему пропуску.
- «Перевести пропуски» отправляет только оставшиеся рамки. Готовый перевод
  и ручные правки сохраняются, а повторно пропущенные рамки остаются в списке.

## Что проверили в Windows Release

- В приложении проверили подписи двух разных моделей и сопоставление обеих рамок
  на встроенном примере промпта OCR с переводом.
- Проверили импорт и экспорт одного шаблона OpenRouter. В экспортированном
  файле сохранилась переменная `{{api_key}}`.
- Прошли 29 автотестов, в том числе разбор вставленного HTTP-ответа и возврат
  к настройкам подключения после отключения шаблона OpenRouter.
- Сетевой прогон пользовательских HTTP-запросов OpenRouter остаётся отдельной
  проверкой. В последнем Release эти сценарии проверялись локально.

## Чаты с локальной историей

- «Чаты» открываются отдельной кнопкой на верхней панели. При создании
  диалога можно выбрать OpenRouter или сохранённый профиль «Свой сервер».
  Чат использует модель, активный ключ и шаблон запросов этого подключения.
- Можно искать по названию диалога и по сообщениям в открытом чате. Диалоги
  можно переименовать, закрепить, удалить и переместить в папку. Закреплённые
  идут первыми. В каждой группе новое сообщение поднимает диалог вверх.
- У каждой защищённой папки свой пароль. Заголовки чатов, сообщения и
  изображения в ней хранятся в зашифрованном виде. Имя папки видно в списке.
  Папку можно заблокировать сразу или автоматически через 30 минут, 60 минут
  либо при следующем запуске. Последний вариант выбран по умолчанию.
- Расположение библиотеки и время блокировки задаются кнопкой «Хранилище
  чатов». Выбор другого расположения открывает библиотеку в выбранной папке.
  При отправке запроса с изображением приложение показывает адрес и спрашивает
  подтверждение, включая повторную отправку изображений из истории.
- В Windows Release проверили отправку текста и изображения через локальный
  профиль, отсутствие запроса после отмены, порядок диалогов после отправки,
  переименование, закрепление, оба вида поиска и открытие истории защищённой
  папки. После перезапуска папка снова закрыта. Неверный пароль и блокировка
  по таймеру покрыты автотестами.

## Дополнительные форматы HTTP

- В настройках переводчика OpenRouter и каждого профиля «Свой сервер» есть переключатель «Потоковый ответ (SSE)» для API, совместимых с OpenAI Chat Completions. Если включён полный HTTP-запрос «Чат и перевод», формат потока определяют правила шаблона.
- Для чатового запроса можно задать правила SSE. В чате текст появляется по мере поступления событий. OCR и перевод разбирают рамки после завершения потока.
- В полном HTTP-запросе можно настроить multipart-поля и передавать вложения. Сетевой OCR использует бинарные части для изображений рамок. Примеры обоих форматов есть в промпте для настройки «Своего сервера».
- В Windows Release проверили оба формата одним запросом через локальный сервер. После отмены файл не отправился. После подтверждения сервер получил исходные байты, а в чате появился первый фрагмент до завершения ответа. Автотесты также проверили несколько файлов в одном поле и подготовку изображений OCR.
- В обычной Windows Release включили SSE переключателем и увидели, как текст появляется до окончания запроса в тестовых чатах OpenRouter (`openai/gpt-4o-mini`) и Claude n Codex (`claude-sonnet-4-6`).

## Проверка HTTP-шаблонов OpenRouter

- В обычной Windows Release проверили три операции с живым OpenRouter и активным пользовательским шаблоном. Тестовый чат получил HTTP 200 и ответ от `openai/gpt-4o-mini`. Каталог загрузился, а сведения о ключе показали лимит, остаток, расход и признак бесплатного тарифа под именами из шаблона.
- Пользовательский каталог OpenRouter использует стандартные пути к цене, дате, размеру контекста, описанию и поддержке изображений. Эти пути можно переопределять в правилах разбора. Автотест проверяет и стандартные пути, и переопределение.
- При загрузке каталога по пользовательскому шаблону приложение запрашивает подтверждение, прежде чем подставить сохранённый ключ. Штатный публичный каталог загружается без ключа.
- После исправлений повторили все три операции в обычном Release. Каталог после подтверждения показал 433 модели с доступными ценами и размером контекста.
