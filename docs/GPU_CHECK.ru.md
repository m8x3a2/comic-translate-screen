# Проверка видеокарты на другом компьютере

Цель: узнать, работает ли программа на видеокарте этого компьютера и насколько это быстрее процессора.
Ничего устанавливать не нужно, программа ничего не отправляет в интернет.

## 1. Распаковать

1. Распакуйте `ComicTranslateScreen-<версия>-windows-x64.zip` в любую папку, например `C:\ComicTranslateScreen`.
2. Если Windows спросит, разрешить ли запуск программы от неизвестного издателя, нажмите «Подробнее» → «Выполнить в любом случае».

## 2. Модели

Модели в архив не входят: нужные для английского — около 45 МБ, все — около 370 МБ. Подойдёт любой из двух способов.

- **Перенести с другого компьютера (без интернета).** Скопируйте папку
  `%LOCALAPPDATA%\ComicTranslateScreen\models` на флешку и положите её по тому же пути на этом компьютере.
  Путь можно вставить в адресную строку Проводника.
- **Скачать.** Запустите `comic_translate.exe` → «Настройки» → «Модели» → «Скачать нужные».

## 3. Тест скорости в окне программы (главное)

1. Запустите `comic_translate.exe` → «Настройки» → «Общие» → «Проверить скорость».
2. Около минуты программа прогоняет тестовую страницу на процессоре и на видеокарте, потом показывает
   время каждого и что выгоднее. Сделайте снимок этого окна.
3. Если видеокарта не справилась хотя бы с одним шагом, программа сама сохраняет отчёт для разработчика:
   путь к нему написан в окне, кнопка «Показать в папке» открывает его.
4. Шаги, которые на этой видеокарте не работают, программа запоминает: они видны под переключателем
   «Использовать видеокарту» и дальше сразу считаются на процессоре. «Попробовать снова» снимает эту отметку
   (например, после обновления драйвера).

## 4. Замеры в терминале (дополнительно)

1. Откройте папку программы в Проводнике, щёлкните по пустому месту правой кнопкой → «Открыть в Терминале».
2. Выполните по очереди (каждая команда — одна строка):

```
.\cts.exe doctor > doctor.txt
.\cts.exe bench samples\en_E01P01.jpg samples\en_E06P05.jpg samples\ja_E01P02.jpg > bench_cpu.txt
.\cts.exe bench samples\en_E01P01.jpg samples\en_E06P05.jpg samples\ja_E01P02.jpg --gpu > bench_gpu.txt
.\cts.exe report -o report.zip
```

Каждый замер идёт 1–5 минут; пока он идёт, компьютер лучше не нагружать.
Если какая-то модель не справится на видеокарте, замер не прервётся: она продолжит на процессоре,
а в терминале появится предупреждение — скопируйте его текст.

## 5. Обычная работа с видеокартой

Если тест посоветовал видеокарту, включите её и переведите несколько страниц («Перевести всё»).
Время видно внизу окна («Переведено 3 из 3 страниц за 0:12») и по кнопке «Отчёт».
Если видеокарта посреди работы не справится, сверху окна появится надпись со значком ⚠ — она не исчезнет, пока её не закрыть.
Нажмите в ней «Собрать отчёт об ошибке».

## 6. Что прислать

Снимок окна из пункта 3, все отчёты `bugreport-….zip` (программа пишет, где они), а если делали пункт 4 —
`doctor.txt`, `bench_cpu.txt`, `bench_gpu.txt`, `report.zip` и текст предупреждений из терминала.
В отчётах нет ключей API и картинок страниц; в них есть названия видеокарт, версии драйверов и журнал программы.

## Если что-то не так

- **Ошибка про `VCRUNTIME140.dll` или `MSVCP140.dll`.** Установите «Microsoft Visual C++ Redistributable (x64)» с сайта Microsoft.
- **Видеокарта не найдена, хотя она есть.** Обновите драйвер с сайта NVIDIA, AMD или Intel и проверьте ещё раз.
- **Программа не запускается совсем.** Пришлите текст ошибки или снимок экрана.
